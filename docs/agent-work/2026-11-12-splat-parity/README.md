## ۲. آنچه ساخته و منتشر شد

1. **`skills/bake_splat.py --density`** — چگالی پخت، و ثبت `photo_px_per_splat`
   در DB. عدد تیزی حالا بخشی از خروجی است، نه سلیقه.
2. **پخت پیکسلی دمو** — `make_demo_splat.py` روی `W*H` = ۵۲۴٬۲۸۸ گاوسین
   (۳۵.۶۵ MB PLY).
3. **`skills/spz_lod.py`** — PLY → SPZ v2 (gzip) + چهار سطح LOD + manifest +
   verify مستقل. ۳۵.۶۵ MB → **۴.۲۱ MB** (۸.۵×).
4. **`public/js/spz.js`** — خوانندهٔ SPZ در مرورگر (DecompressionStream)،
   همان شکل دادهٔ رندرر EWA.
5. **انتخاب سطح در lab** + HUD (سطح، px/splat، کانتینر، حجم) + `?lod=0..3`.
6. **`public/labs/engine-v1/vq11.js`** — سیاست Lane C روی پیج مرادی: تا
   `SAFE_R` عکس مرجع است و splat اصلاً رسم نمی‌شود؛ `?fill=1` رفتار قدیمی.
