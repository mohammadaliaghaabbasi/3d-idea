## ۱. سؤال لوپ

از **یک** پانوراما + عمق متریک، کدام پیکربندی splat بهترین تصویر را می‌دهد وقتی
دوربین دور می‌شود؟ پاسخ باید عدد باشد، نه سلیقه.

## ۲. چرا می‌توان بدون GPU سنجید

اتاق آزمایشی **تحلیلی** است: دیوارها (۴×۲.۱ متر)، کف (y=−۱.۶)، سقف (y=+۰.۹) و دو
جعبهٔ مبلمان دقیقاً معلوم‌اند. پس تصویر مرجع در هر ژست دوربین با ray-cast دقیق
ساخته می‌شود (`raycast` + `surface_colour`)، و هیچ «حقیقت تقریبی» در سنجه نیست.

## ۳. لوپ

```
bash scripts/rd_converge.sh            # calibration + loop تا همگرایی
bash scripts/rd_converge.sh --quick    # اسموک: ۳ نامزد، ۲ تکرار
```

1. **Calibration (گیت):** ابری از خودِ دوربین مرجع ساخته و دوباره رندر می‌شود
   (یک splat به‌ازای هر پیکسل، شعاع زیرپیکسلی). سنجهٔ سالم باید تصویر مرجع را
   بازتولید کند: **PSNR ≥ ۳۰ dB و پوشش ≥ ۹۸.۵٪**. اگر رد شود، لوپ *اجرا نمی‌شود*
   (چون رتبه‌بندی روی سنجهٔ خراب = نویز).
2. **جست‌وجو:** شبکهٔ اولیهٔ `density ∈ {0.25,0.5,0.75,1,1.5,2}` ×
   `sigma ∈ {0.5,0.75,0.9,1.2,1.5}` (۳۰ نامزد)؛ سپس هر تکرار ناحیهٔ جست‌وجو
   را نصف می‌کند. محور `aspect` حذف شد: رندرر دوبعدی، امتداد عمق را نشان نمی‌دهد،
   پس جست‌وجو روی آن فقط نویز رتبه‌بندی می‌کرد.
3. **امتیاز:** `mean PSNR(0, 0.5, 1.0 m) − 0.35 × MB برآوردی` (تراز صریح کیفیت/حجم).
4. **توقف:** وقتی بهبود بهترین امتیاز < `0.05 dB` شود، یا سقف تکرار.

خروجی: `rd_results.json` با تاریخچهٔ هر تکرار، top-5 هر تکرار، و برنده.

## ۴. چه چیزی در نسخهٔ اول خراب بود (و اصلاح شد)

اجرای اول `8.66 dB` داد — عددی که فقط یک معنی دارد: **سنجه خراب بود، نه ابر**.
سه ریشه پیدا و رفع شد:

| نقص | اثر | اصلاح |
|---|---|---|
| کرنل با باکِت شعاع صحیح و افت `0.5·rad` | لبهٔ splatهای بزرگ تقریباً بی‌وزن → حلقه/نقطه‌های تیره | کرنل گاوسی واقعی روی پنجرهٔ ۲σ، جدول‌شده برای هر باکِت σ |
| تقسیم‌های `0/0` در ray-cast | NaN → پرتوهای «بی‌برخورد» با رنگ مشکی | `_safe_div` که موازی‌ها را `inf` می‌کند (بدون NaN) |
| رنگ نقطه‌های بی‌برخورد = `0.05` | نقطه‌های سیاه پراکنده در تصویر | اتاق بسته است؛ اگر پرتویی برخورد نکند، **AssertionError** می‌دهد تا ساکت خراب نشود |
| `np.round` روی u/v | مرکز پیکسل دقیقاً `.5` می‌افتد و `round` نیم‌به‌زوج است: هر ستون دوم روی همسایه می‌افتد و ستون‌های بین خالی می‌مانند | `np.floor` (پیکسل `px` → `px`) |
| `step = round(1/density)` | ۰.۵/۰.۷۵/۱ همه یک ابر می‌دادند؛ نصف شبکهٔ جست‌وجو تکراری بود | `n = round(density·pixels)` و نمونه‌برداری با `linspace` |
| محور `aspect` | در رندرر دوبعدی اثری نداشت → رتبه‌بندی روی نویز | حذف شد |

اضافه: `EPS_SIGMA_PX = 0.45` (low-pass مثل GLSL)، سقف σ = ۶ پیکسل، و شمارش
باکت‌ها با `digitize`-مانند برداری.

**سقف `density`:** برای `density ≥ 1` تعداد splat همیشه ۵۲۴٬۲۸۸ می‌ماند، چون برابر

بیشتر از ۱.۰ پیکسل‌عکس بر splat نمی‌شود خواست؛ برای تیزتر شدن باید نمونه‌برداری
دقیق‌تر (چند پانوراما / عمق با کیفیت بالاتر) داشت، نه density بالاتر. این تنها
نتیجهٔ منفیِ قابل‌اندازه‌گیریِ کل لوپ است و دقیقاً همان چیزی است که در گزارش
`splat-parity` با `px_per_splat` اندازه گرفتیم.
