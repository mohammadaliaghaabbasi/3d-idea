## تصمیم‌های تازه قفل‌شده (فاز ۱ — ۲۰۲۶-۱۱-۰۱)

- **استک فاز ۱:** Three.js + GSAP (نسخه آزاد) + کره‌ی جابه‌جاشده‌ی WebGL + محتوای PolyHaven (CC0).
- **عمق v1:** پریور تحلیلی اتاق‌جعبه‌ای (seamless، آفلاین) + هوک ارتقا به DA2/PanDA (`--depth-backend replicate-da2`).
- **درگاه‌ها v1:** مختصات دیوار + پاس بینایی هوش مصنوعی (VLM) برای تشخیص درهای واقعی (`data/vision_overrides.json`).
- **دیتابیس اتاق‌ها:** `data/rooms_db.json` (canonical) + کپی استاتیک در `public/data/` برای دیپلوی.
