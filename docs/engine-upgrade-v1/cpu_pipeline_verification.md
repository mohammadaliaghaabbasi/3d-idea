## ۵) محدودیت‌های صادقانه (بدون تغییر در موتور، طبق دستور)

1. **مقیاس نسبی نه متری قطعی:** DAV2-small disparity نسبی تخمین می‌زند؛ k=7.153 یک **تخمین مقیاس
   قابل‌تنظیم** است که فرض CAM_H=1.5m را روی صفحهٔ کف می‌نشاند. تا وقتی یک مرجع اندازه‌گیری‌شدهٔ
   واقعی (مثلاً عرض واقعی در) وارد خط تولید نشود، همهٔ «متر»های خروجی باید نسبی-کالیبره خوانده شوند.
2. **حفرهٔ disocclusion در جابه‌جایی:** دیده شدن مناطق uncover شده در حرکت، محدودیت ذاتی
   بازسازی تک‌پانوراماست (نه باگ) — در PHASE 6 به‌صورت کمی و در PHASE 5 با پس‌زمینهٔ پانو مدیریت می‌شود.
3. **Spherical harmonics صفر:** splat ها فقط رنگ DC دارند (SH degree 0) — برای بازسازی
   عکس‌محور کافی و درست است؛ جلوهٔ view-dependent واقعی (براقیت) وجود ندارد.
4. **حجم PLY:** 32.82MB برای وب سنگین است → دقیقاً همان چیزی که PHASE 3 با SPZ حل می‌کند.
