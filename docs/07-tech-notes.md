# نکات فنی، منابع محتوا و ملاحظات قانونی

> نسخه v1 — نوامبر ۲۰۲۶ (استخراج از گفتگوی منبع)

## استک پیشنهادی

- **فرانت‌اند:** Three.js (WebGL) + GSAP (ScrollTrigger) + React/Next.js
- **بک‌اند:** API + دیتابیس گراف اتصال درها (`spatial_graph`)
- **رندر پانوراما:** کره‌ی دوگانه با کراس‌فید (Dual-Sphere Crossfade) + تکسچر Equirectangular؛ تبدیل به WebP یا KTX2 در سه کیفیت (موبایل / دسکتاپ / VR)
- **میزبانی:** Cloudflare Pages

## خط تولید عمق (Depth Pipeline)

`panorama (equirect)` → مدل عمق (Depth Anything V2 / Marigold با Wrap-around برای بسته شدن درز ۳۶۰) → مش جابه‌جاشده (High-Poly Displaced Sphere) → Safe Walk Zone (شعاع حرکت مجاز + مسیرهای خطی به سمت درها)

## منابع محتوای مجاز (برای شروع)

- **منابع آزاد:** PolyHaven، Chaos Cosmos، گالری‌های عمومی فروم‌های D5 Render و Corona — رندرهای ۳۶۰ باکیفیت تحت لایسنس CC0 یا قابل دانلود مستقیم، با فایل خام JPG/HDR برای تست موتور.
- **آثار Kuula:** فقط با اجازه‌ی صاحب اثر یا در قالب Embed قانونی با ذکر نام و لینک طراح (پروفایل طراح همیشه در اطلاعات تور موجود است).
- **مسیر بلندمدت:** دعوت مستقیم طراحان برای آپلود فایل اصلی — خیلی از طراحان اگر ببینند اثرشان به شکل یک داستان سینمایی و اسکرولی همراه با لینک مستقیم به پورتفولیو و پیجشان نمایش داده می‌شود، با کمال میل فایل اصلی پانوراما را می‌فرستند.

## محدودیت‌ها و خطوط قرمز

- **محدودیت iframe:** به دلیل سیاست‌های امنیتی مرورگر (CORS / Cross-Origin)، سایت ما نمی‌تواند به کدهای داخل iframe کوئلا دستور بدهد (مثلاً «با اسکرول، دوربین را ۳۰ درجه بچرخان»). iframe مثل یک جعبه‌ی بسته عمل می‌کند؛ برای تجربه‌ی اسکرولی، تصویر خام باید در موتور خودمان رندر شود.
- **محدودیت گرافیکی Kuula:** برای لود سریع، کوئلا تصویر را به ۶ وجه مکعب (Cube Map) و تایل‌های کوچک تقسیم می‌کند تا فایل اصلی یکپارچه به‌سادگی قابل برداشتن نباشد.
- **خط قرمز:** برداشتن فایل خام از پشت کدهای Kuula بدون اجازه‌ی طراح، خلاف قوانین پلتفرم است.
- **استراتژی جایگزین:** تعریف پلتفرم به‌عنوان «مجله‌ی تعاملی معماری» (Interactive Architectural Curation) — نمایش اثر با نام و لینک طراح.

## نکات کیفیت و عملکرد
